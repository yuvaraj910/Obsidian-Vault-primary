# Weekly Second Brain Review

**Run:** Saturdays at 11 PM (local time)  
**Related:** [[Sorting System]] · [[Planning/2026-11-01 - My Weekly System|Weekly timetable]] · [[Planning/to do list/To do lists|To-do list index]]

## 1. Update and Audit Obsidian

*Goal: Keep the vault accurate, organized, searchable, and useful.*

- [ ] Process new notes and captures from the inbox.
- [ ] Put unprocessed notes in their correct locations using [[Sorting System]].
- [ ] Update an existing note when new information belongs there instead of creating a duplicate.
- [ ] Review notes created or modified during the past week.
- [ ] Check for obvious duplicate notes and redundant information.
- [ ] Fix important broken or incorrect internal links.
- [ ] Review relevant project notes, learning notes, resources, and reusable procedures.
- [ ] Remove outdated information only when its replacement or irrelevance is clear; preserve it when uncertain.
- [ ] Identify organizational problems that need a future fix.
- [ ] Record important unfinished cleanup tasks rather than expanding the review indefinitely.

**Database protection:** Never edit, rename, move, reorganize, or delete anything inside Databases/ without explicit permission for that specific change. Auditing the vault does not authorize modifying database contents.

Do not spend the entire session reorganizing. Fix small issues and record larger improvements for a separate task.

## 2. Update Notion Progress

*Goal: Keep progress records accurate and consistent with what actually happened.*

- [ ] Review current Notion study and progress trackers.
- [ ] Update the skills and topics genuinely studied this week.
- [ ] Record completed lessons, exercises, coding practice, and projects where relevant.
- [ ] Update project and job-search progress if applicable.
- [ ] Mark tasks complete only when they are actually finished.
- [ ] Identify stalled tasks and decide whether to continue, reschedule, reduce, or drop them.
- [ ] Ensure next week's priorities are reflected in the appropriate Notion pages or databases.
- [ ] Check that progress records are not duplicated across Notion and Obsidian unnecessarily.
- [ ] If Codex cannot access Notion, list the updates for me to complete manually; do not claim they are done.

Use Notion for the structured tracking already established there. Use Obsidian for durable knowledge, explanations, connected notes, and documentation. Link or reference information across both systems when useful instead of copying everything into both.

## 3. Review the Previous Week and Plan the Next Week

*Goal: Turn the previous week's experience into a realistic plan.*

- [ ] Review last week's goals and planned tasks.
- [ ] Mark completed, partially completed, and unfinished goals accurately.
- [ ] Identify what helped progress and what caused delays.
- [ ] Note important lessons, recurring problems, and changes in priorities.
- [ ] Choose a maximum of three major outcomes for the coming week.
- [ ] Break each outcome into small, concrete next actions.
- [ ] Assign priorities based on deadlines, importance, and available time.
- [ ] Account for college, exams, work, personal commitments, and rest where applicable.
- [ ] Schedule demanding work realistically instead of filling every available hour.
- [ ] Carry forward only unfinished tasks that still matter.
- [ ] Define what success will look like by the next Saturday review.

Keep the plan achievable. Do not turn every interest into a commitment.

## 4. Plan New Skills, Ideas, and Projects

*Goal: Keep learning and experimentation moving without spreading attention too thin.*

- [ ] Review new skills, technologies, ideas, and projects that caught my attention this week.
- [ ] Identify which ideas support my current learning path, career goals, or active projects.
- [ ] Decide whether each worthwhile idea should be learned now, added to a future backlog, saved as a resource, or set aside.
- [ ] Choose at most one new skill or topic for the coming week, and only if capacity allows.
- [ ] Define a specific learning outcome for that skill.
- [ ] Choose the first practical exercise, experiment, or small project.
- [ ] Find or select a useful learning resource if one is needed.
- [ ] Add the new commitment to the appropriate tracker or planning note.
- [ ] Avoid starting another course or project simply because it looks interesting.
- [ ] Prefer continuing existing work when it has more value than starting something new.

A new skill is optional each week. If exams, deadlines, or existing projects require attention, prioritize those instead.

## 5. Finalize and Close the Review

- [ ] Confirm that the important Obsidian cleanup is complete.
- [ ] Confirm that Notion progress is updated, or note what remains to be done manually.
- [ ] Save next week's priorities in the appropriate planning location.
- [ ] Ensure every major goal has a clear next action.
- [ ] Record decisions or changes that should be revisited later.
- [ ] Check that no protected files or unrelated areas were modified.
- [ ] Finish the session without adding unnecessary new tasks.

## Session Rules

- Work through the sections in order.
- Focus on meaningful changes, not perfect organization.
- Use existing notes, templates, and trackers wherever possible.
- Do not create extra documents for every review or duplicate this checklist each Saturday.
- Do not automatically create a new skill, course, project, or workflow.
- Put larger maintenance tasks in the existing task system at [[Planning/to do list/To do lists|To-do list index]] for a separate session.
- If a task requires external access or manual action, mark it as pending rather than pretending it was completed.
- Never delete information or modify protected databases without authorization.
