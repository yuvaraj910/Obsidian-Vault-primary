# Daily Learning Workflow

## Purpose

Learn actively, practice deliberately, and make tangible progress on a
project. Keep daily sessions focused on learning and building.

## Workflow

### 1. Learn

-   Choose one concept connected to the current learning goal.
-   Study a concise explanation and a few examples.
-   Ask for clarification when something is unclear.

### 2. Explain

-   Explain the concept in your own words.
-   Work through a small example without copying the explanation.
-   Revisit only the part that remains unclear.

### 3. Solve Problems

-   Apply the concept through coding exercises.
-   Start with a straightforward problem, then increase difficulty.
-   Attempt the solution independently before asking for help.

### 4. Review Code

-   Check whether the solution works.
-   Look for readability, sensible naming, and unnecessary complexity.
-   Understand any suggested changes before applying them.

### 5. Identify Weaknesses

-   Identify the exact concept, syntax, or reasoning step causing
    difficulty.
-   Avoid vague conclusions such as "I'm bad at coding."
-   Turn each difficulty into a specific practice target.

### 6. Targeted Practice

-   Solve additional problems that target the identified weakness.
-   Return to the main learning goal once the weakness is clearer.

### 7. Build

-   Apply the learning to a small feature or project.
-   Prioritize working software and meaningful progress over perfection.

## Daily Rules

-   Keep Python and DSA as the main priorities unless the current plan
    says otherwise.
-   Capture unrelated ideas in a Later List instead of switching tasks.
-   Use AI as a tutor and reviewer, not as a replacement for your own
    problem-solving.
-   Do not require a quiz, interview practice, or formal end-of-day
    review.
-   Git commits may happen during development when useful; the formal
    project review and documentation workflow is weekly.

## Definition of a Good Session

A session is productive when it produces at least one meaningful
result: - a concept understood, - a problem solved, - a weakness
identified and practiced, - a feature implemented, or - a project
advanced.

The goal is consistent progress, not completing every stage perfectly
every day.
